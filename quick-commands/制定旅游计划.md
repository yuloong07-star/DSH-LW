# 制定旅游计划

把"哪一天去、那天天气怎么样、那天有没有空、当地有什么值得去"排成一份能落进日历的行程。

1. 先问清楚 (缺哪个问哪个, 一次最多问两个): 去哪 (城市 / 景区)、几天、从哪天开始、和谁去、有没有非去不可的地方
2. 加载技能的 `weather` 那份, 查目的地未来三天的天气; 有雨 / 大风就换一天备选, 并说清是因为哪一条
3. 加载技能的 `calendar` 那份, 用 `lw_calendar op=free` 查这几天 09:00-22:00 的空档, 挑出真正能用的一到两天
4. 加载技能的 `web-search` 那份, 搜目的地的开放时间 / 要不要预约 / 门票与交通, 并查当地天气下合适的玩法
5. 排期: 每天 2-4 条 (出发 / 主景点 / 吃饭 / 机动), 用 `lw_calendar op=create` 一条一条写进日历, 每条带时间与地点
6. 回话: 哪几天去、每天干什么、要提前订什么; 落进日历的每一条都点名日期与时间

边界: 天气查不到、日历没有可写的一本、行程里有必须主人本人决定的部分 (订票 / 请假), 都如实说清并停下等一句答复 —— 不猜着往下排。
