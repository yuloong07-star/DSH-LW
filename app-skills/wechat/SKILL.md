# 微信 (com.tencent.mm)

这份技能由 Luwi 的「技能」那一段按**已安装的应用**一键装进来 (见 `app-skills/catalog.json`):
机器上装了微信, 它才值得在。

## 一条路走完

1. **起它**: `lw_app_control` (起应用那一条) 或 `lw_launch`, 包名就是 `com.tencent.mm`
2. **看**: `lw_ui` 读当前这一屏。会话列表里每一行的文字就是会话名, 所以**按名字点比按坐标稳**
3. **点**: `lw_tap` 按文字点那一行 (工具的说明里有按名字与按坐标两种用法)
4. **打字**: 先点一下输入框, 再 `lw_type`
5. **退**: `lw_key` 发一次 BACK, 回上一层

## 这一行动手之前先问一句

**发消息、转账、删会话、拉黑 —— 出去了就收不回的, 先跟主人确认一次** (Luwi 全局那条规矩:
破坏性操作由提示词层问一次, 应用层不弹窗)。

## 常见活儿

| 想干的事 | 怎么走 |
| :-- | :-- |
| 谁刚说了什么 | `lw_ui` 看会话列表 → 点那个会话 → 再 `lw_ui` 读正文 |
| 回一句话 | 点会话 → 点输入框 → `lw_type` → 点「发送」(发之前问一次) |
| 没读的消息 | `lw_notifications` 看通知栏那几条; 点某条通知会直接进那个会话, 比在列表里找快 |
| 找一个人 | 会话列表顶部那个搜索入口, 点它再 `lw_type` |

## 坑

- 微信的点按有它自己的一套: **列表行按名字点得到, 但"发送"那颗按钮常常只有坐标**, 所以先 `lw_ui`
  拿到它的 bounds, 再按坐标点
- 表情面板与输入法会占掉半屏, 打字前先确认焦点真的在输入框 (屏幕下方弹起来的那一栏就是它)
- 首次进某个会话可能要先过一条"加载中", `lw_ui` 隔一秒再读一次
