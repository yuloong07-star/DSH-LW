# 抖音 (`com.ss.android.ugc.aweme`, 极速版 `…aweme.lite`)

由 Luwi 的「技能」那一段按已安装的应用一键装进来。

## 先记住这一条

**抖音的画面是图层不是控件**: `lw_ui` 读到的只有账号名、标题、按钮那几行字, 视频本身读不出来。
要"看"视频内容只能 `lw_screenshot` 截图 (它会把整屏拍下来), 而截图对模型来说是一张图, 不是文字。
所以**给主人汇报时只说屏幕上读得到的那些** (谁发的、写了什么、多少点赞), 不要编画面里的内容。

## 一条路走完

1. **起它**: `lw_app_control` (起应用) 或 `lw_launch`, 包名见上
2. **翻**: `lw_gesture` 往上滑一次 = 下一个视频 (一次一屏, 翻完**重新 `lw_ui`\*\*)
3. **搜**: 点右上角放大镜 → `lw_type` 关键词 → 选「视频 / 用户 / 商品」那一栏
4. **看评论**: 点右下角评论图标 → `lw_ui` 读评论; 评论区是**可滚的长列表**, 用 `lw_scroll`
5. **退**: `lw_key` 发 BACK

## 常见活儿

| 想干的事 | 怎么走 |
| :-- | :-- |
| 找某个人的主页 | 搜那个名字 → 「用户」那一栏 → 点进主页 |
| 某个视频写了什么 | 翻到它 → `lw_ui` 读标题与话题标签 |
| 评论里大家在说什么 | 打开评论区 → 读前一两屏 |
| 关注 / 点赞 | **这一类"替主人表态"的动作先问一次** |

## 坑

- 开屏与信息流里全是广告, 而且**广告也会被读成一条正常的视频**, 别把它当成主人要的那个
- 上下滑是**全屏手势**, 滑到屏幕边缘会误触返回
- 直播页会一直放声音: 主人没让看直播就不要点进直播间
