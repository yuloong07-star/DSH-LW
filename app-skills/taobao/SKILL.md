# 淘宝 (com.taobao.taobao)

由 Luwi 的「技能」那一段按已安装的应用一键装进来。

## 一条路走完

1. **起它**: `lw_app_control` (起应用) 或 `lw_launch`, 包名 `com.taobao.taobao`
2. **搜**: 点顶部搜索框 → `lw_type` 关键词 → `lw_key` 发 ENTER (工具说明里按名字发键那一条)
3. **看**: `lw_ui` 读结果列表; 列表是**两列瀑布流**, 屏幕上的文字就是标题与价格
4. **点进详情**: `lw_tap` 按标题点
5. **往下翻**: `lw_scroll` 一次一屏, 之后**重新 `lw_ui`** (翻完屏幕上的字全变了)

## 下单那一步交给主人

**加购物车可以, 下单、付款、买票、充值一律停下来问主人。** 淘宝的确认页会把地址与优惠都列出来,
把那一页读给主人听, 由主人按最后那一下。

## 常见活儿

| 想干的事 | 怎么走 |
| :-- | :-- |
| 找一件东西 | 搜索那个词, 读前三屏的标题与价格, 挑几条给主人 |
| 某家店里的东西 | 搜到店 → 点「进店」→ 再搜 |
| 我的订单到哪了 | 「我的淘宝」→ 我的订单 → 读列表; 点进去看物流 |
| 购物车里有什么 | 「购物车」→ `lw_ui` 读列表 |

## 坑

- 开屏广告 (三秒跳过那种) 很常见: 先看有没有「跳过」, 点掉再往下做
- 商品详情的价格常常要**往下翻一段**才加载出来
- 「立即购买」与「加入购物车」挨得很近, 按名字点, 不要按坐标瞎点
