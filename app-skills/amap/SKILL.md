# 地图 (高德 `com.autonavi.minimap` / 百度 `com.baidu.BaiduMap`)

由 Luwi 的「技能」那一段按已安装的应用一键装进来: **装的是哪一家, 就用哪一家的包名**。

## 一条路走完

1. **起它**: `lw_app_control` (起应用) 或 `lw_launch`
2. **搜地点**: 点顶部搜索框 → `lw_type` 地点名 → `lw_key` 发 ENTER
3. **看结果**: `lw_ui` 读列表 (**第几条、多少公里、大概几分钟** 都在那一行字里)
4. **看路线**: 点某条结果 → 点「路线」→ 选出行方式 (开车 / 公交 / 走路 / 骑行) → `lw_ui` 读方案
5. **读给主人听**: 把"全程多少公里、大概多久、走哪条主路"说清楚, **不要把屏幕上一长串都念一遍**

## 起点默认是"我的位置"

地图自己会取当前位置, 所以**先确认顶部那一行显示的是这台手机现在所在的地方** (第一次用可能要授权定位,
那一步要主人点)。主人要是说"从某地到某地", 那就在「起点」那一栏改成那个地方。

## 常见活儿

| 想干的事 | 怎么走 |
| :-- | :-- |
| 从这儿到某地怎么走 | 搜目的地 → 路线 → 读第一条方案 |
| 附近有什么 | 搜「附近的加油站 / 药店 / 停车场」这类词, 读前几条 |
| 这个地方在哪 | 搜名字 → 长按地图看坐标那一栏 (`lw_ui` 能读到经纬度与行政区) |
| 打车 | 路线页里「打车」那一条能叫车 —— **叫车要花钱, 先把车型与预估价格读给主人, 由主人按** |

## 坑

- 地图大部分是**图层**, 无障碍树里读不到地名: 所以"看地图"要靠搜索框与列表, 不要指望读屏幕中心
- 路线页方案是**横向卡片**, 要左右滑 (`lw_gesture` 或 `lw_scroll` 的横向那一种) 才看得到后面几条
- 导航一旦点开始就是"一直说话"的东西, 不要在没人看着的时候替主人开
