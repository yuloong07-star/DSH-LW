# 支付宝 (com.eg.android.AlipayGphone)

由 Luwi 的「技能」那一段按已安装的应用一键装进来。

## 一条路走完

1. **起它**: `lw_app_control` (起应用) 或 `lw_launch`, 包名 `com.eg.android.AlipayGphone`
2. **看**: `lw_ui` 读屏。首页那一屏的字很多, **先找那几个关键字** (扫一扫 / 收付款 / 卡包 / 我的)
3. **点**: `lw_tap` 按文字点
4. **打字**: 先点输入框再 `lw_type` (搜索框、转账金额框都是这一条)
5. **退**: `lw_key` 发 BACK

## 钱的事一条都不自己走完

**付款码、转账、确认支付、开通任何服务 —— 到了要按下去那一步就停下来问主人。**
这条不是"建议", 是 Luwi 的规矩: 应用层不拦, 提示词层必须问。

可以替主人做的: 找到那个页面、把金额填进去、读出账单上的数字。**不能替主人按的**: 任何一颗要钱的
按钮、任何一次指纹/面容确认。

## 常见活儿

| 想干的事 | 怎么走 |
| :-- | :-- |
| 这个月花了多少 | 「我的」→ 账单 → `lw_ui` 读列表; 太长就 `lw_scroll` 往下翻 |
| 开付款码 | 首页「收付款」→ 打开之后**交给主人**, 不要停在条形码页上 |
| 查一笔转账 | 「我的」→ 账单 → 点那条 → `lw_ui` 读明细 |

## 坑

- 首页是**可下滑的长页**, 每屏能看到的入口不一样: 找不到就 `lw_scroll` 再 `lw_ui`
- 有弹窗 (活动 / 升级提示) 会盖住真内容, 先看 `lw_ui` 里有没有「关闭」这一类文字
- 涉及钱的页面**别截图往外发** (保单号、银行卡尾号都在上面)
