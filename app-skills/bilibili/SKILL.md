# 哔哩哔哩 (`tv.danmaku.bili`)

由 Luwi 的「技能」那一段按已安装的应用一键装进来。

## 一条路走完

1. **起它**: `lw_app_control` (起应用) 或 `lw_launch`, 包名 `tv.danmaku.bili`
2. **搜**: 点顶部搜索框 → `lw_type` 关键词 → `lw_key` 发 ENTER
3. **看结果**: `lw_ui` 读列表 (**标题 / UP 主 / 播放量 / 时长** 都在那一行里); 上面还有「综合 / 视频 / 番剧 / 用户」那一排要挑一栏
4. **点进去**: `lw_tap` 按标题点; 视频页的简介与评论区用 `lw_ui` 就能读到字
5. **往下翻**: `lw_scroll` 一次一屏, 之后重新 `lw_ui`

## 投币、点赞、关注要问一次

这三颗按钮是"替主人表态"的: **按之前先问, 按完把结果说清楚** (投了几个币、关注了谁)。

播放本身可以替主人开 (它不改变任何账号状态), 但**别在没人听的时候让它一直放**。

## 常见活儿

| 想干的事 | 怎么走 |
| :-- | :-- |
| 某个人最近更新了什么 | 搜名字 → 「用户」那一栏 → 进主页 → 读投稿列表 |
| 这个视频多长、什么时候发的 | 点进去 → `lw_ui` 读标题下面那一行 |
| 评论区在说什么 | 往下滑到评论区 → 读前一两屏 |
| 我收藏/追的番 | 底部「我的」→ 追番 / 收藏夹 |

## 坑

- 视频页是**竖屏也能全屏**的东西: 不小心点进全屏就 `lw_key` 发 BACK 出来
- 弹幕开着的时候屏幕上会多出一堆飘过去的文字, 它们**在无障碍树里也会露出来**, 读评论时别把它们
  当成正文
- 开屏广告照旧先找「跳过」
